卷积核到底是什么？

2. 为什么一个核能提取一种特征？

“比较左右”的核把右列相加，再减去左列。右亮左暗时结果为正，左右同样亮时结果为 0，右暗左亮时为负。于是它能对这种亮度变化产生响应。它在各位置都使用同样的规则，所以边界移到哪里，响应也会跟着移动。

一个核 → 一个输出通道；两个核 → 两个输出通道。上面是固定的两种规则对比，不随编辑器变化。每张输出图中的各个格子，是同一个核在不同位置上的结果。

这里的核是人工设计的，便于理解计算。真实 CNN 通常先随机初始化权重，再根据训练损失，通过反向传播更新这些数。训练会改变核的数值，但同一层中，同一个核始终在各空间位置共享使用。学到的核不一定能命名为“边缘”或某个固定的物理属性。

3. 再回到 SRT：183 和 96 分别在哪里？

前面只有一个输入通道，所以一个核只需要一张 3 × 3 权重表。RGB 有 3 个输入通道时，一个核会为每个通道各配一张表，将三个通道的乘积一起求和，仍然只产生一个输出值。

一个 RGB 卷积核：3 × 3 × 3 = 27 个权重
输出一个数 = R 通道的 9 项乘积之和 + G 通道的 9 项乘积之和 + B 通道的 9 项乘积之和

SRT 第一层的输入有 183 个通道，同样的规则扩展为：

3 × 3

核在图像平面上覆盖的大小：每个输入通道都读取 9 个位置。

× 183

一个核跨过全部 183 个输入通道，共 1,647 个权重。

96 个这样的核

每个核各算一张输出图，因此输出有 96 个通道。

同一位置的 3 × 3 × 183 个输入数值
├─ 与第 1 个核的权重乘加 → 输出通道 1 的一个数
├─ 与第 2 个核的权重乘加 → 输出通道 2 的一个数
└─ ……第 96 个核 → 输出通道 96 的一个数

96 是网络设计者选定的核的数量。183 是输入通道数，两者不必相等。步长控制在哪些位置计算，不决定有多少个核。

独立讲解 · 卷积算完以后发生什么

ReLU 是什么？负数归零，正数保留

ReLU 是一种激活函数：对卷积算出的每个数，负数改为 0，零和正数保持原值。它的全称是 Rectified Linear Unit，常译为“修正线性单元”。

ReLU(x) = max(0, x)　← 在 0 和 x 中取较大的那个
例如：[-3, -1, 0, 0.5, 2] → [0, 0, 0, 0.5, 2]

这里的 x 是卷积乘加后得到的响应值。卷积先算出它，ReLU 再处理它，然后把结果交给下一层。

3. 为什么卷积后还需要这一步？

卷积主要做乘法与加法。如果各层之间没有非线性操作，多层线性／仿射变换仍可合成为一个整体的线性／仿射变换。ReLU 在 0 处引入转折：输入不同，通过和归零的位置也会不同。网络因此可以逐层组合出更复杂的模式。

展开一个两层例子，看看“非线性”是什么意思

假设第一层算 a = 2x + 1，第二层算 y = 3a − 2：

中间没有 ReLU：
y = 3(2x + 1) − 2
= 6x + 1
始终是一条直线。
中间加入 ReLU：
y = 3 max(0, 2x + 1) − 2
x ≤ −0.5 时：y = −2
x > −0.5 时：y = 6x + 1
在 −0.5 处出现转折。

ReLU 的每一段都是直线，但整体不是一条直线，所以它是非线性函数。很多这样的单元组合后，可以形成更复杂的分段关系。

改的是响应值卷积核的权重仍可为负数。ReLU 本身没有需要学习的参数，也不改变核的大小或数量。
不取绝对值，也不变概率ReLU(−3) = 0，不是 3；ReLU(2) = 2，输出并不限于 0～1。
负响应也可能含有信息例如边缘方向相反时会得到负值。ReLU 将它归零，不表示网络已经判断它是错误或噪声。

对应本页的普通 SRTEncoder：各个 3 × 3 卷积后接 ReLU；最后的 1 × 1 通道投影后没有额外 ReLU，因此最终特征并不保证全部非负。

真正的 SRT 第一层会在同一空间窗口中，同时对 183 个通道求和：一个卷积核有 3 × 3 × 183 = 1,647 个权重。96 个不同的卷积核产生 96 个输出通道。通道数由卷积核数量决定，空间大小由步长、padding、核大小决定。

④ 1 × 1 卷积：同一位置上，混合通道

用 3 个输入通道映射为 2 个输出通道作小例子。空间位置不移动，每个输出通道使用不同的一组权重。

x₁ = 2x₂ = 1x₃ = 3
y₁ = 0.5×2 + 0.2×1 − 0.1×3
= 0.9
y₂ = −0.3×2 + 0.4×1 + 0.8×3
= 2.2

实际最后一层采用同一原理：每个位置的 1,536 维向量 → 768 维向量，对应 y = Wx + b，其中 W 的形状是 768 × 1,536。49 个位置共享 W 和 b；7 × 7 的网格保持不变。

⑥ 一根手指看不全，怎样借用其他手指看到的信息？

假设手里有一个彩色方块。拇指相机只看见红色的一角，食指相机却看见了红、蓝两面的交界。处理拇指的这处图像时，也参考食指和其他相机提供的信息，就是这里要理解的“视角融合”。

这些份额是谁决定的？和 Q、K、V 有什么关系？

真实网络会根据当前要处理的记录，与各个来源做匹配，再算出参考份额。Q 和 K 用于算“参考多少”，V 是按份额读回的数字内容。没有规定每台相机永远占多少，也不能保证画面最清楚的一台总是占最多。

训练时，用预测结果与真实答案比较，误差推动网络调整这些计算规则。本页的百分比由我们手工设定，是为了让你看懂过程。

进阶：这一步怎样对应 cross-attention、像素射线和训练损失？

245 个融合 token 还不是 top-view 图像。要产生指定视角的内容，SRT 再引入目标相机的像素射线：每条射线提出一次查询，从融合表示 Z 中读取信息，再预测这个像素的 RGB。

Self-attention：让输入视角彼此交流

Q、K、V 都来自当前输入 token
245 个查询 × 245 个可读取 token

例如，食指图像中的一个局部特征，可以读取拇指、其他手指及本视角的信息。结果仍然是 245 个融合 token。

Cross-attention：按目标视角读取融合表示

Q 来自目标像素的射线
K、V 来自融合后的 Z
M 个查询 × 245 个可读取 token

这里的 M 是要预测的目标像素数。查询改变的是“从哪里、朝什么方向看”，可读取的场景表示仍是同一份 Z。

模型怎么知道哪些视角的信息值得读取？

把 top-view 选作目标视角后，训练时将预测 RGB 与同步采集的真实 RGB 比较，形成均方误差损失。误差通过 decoder、融合 Transformer、共享 CNN 反向传播，更新它们的可学习权重。由这些权重计算出来的 Q、K、V 和注意力分配也随训练改变。对应训练实现中的 compute_loss 与 train_step。

重建图像与对齐整体特征，是两个不同的训练目标。原 SRT 的这条路径输出 RGB。如果我们的目标是让五路指尖特征对齐到 top-view 的整体特征，还需要选择 top-view 特征编码器、读取或聚合方式，以及特征对齐损失；不能把它当成原 SRT 已经提供的现成输出。

五路相机都没看到的表面，模型只能利用训练中学到的规律进行推测，不能保证还原真实细节。相机标定、同步、物体遮挡和训练数据覆盖范围，也会影响最终表现。

本节展示计算与监督思路，不展示已训练的注意力结果。预测路径依据 SRT decoder 实现；特征对齐一段是针对我们后续多视角特征训练目标的设计说明。

Q、K、V 大白话：查什么、怎么挑、拿回什么
先用日常生活理解，再对应到手指相机

Q、K、V，说白了就是“我要找什么、这份资料讲什么、里面具体有什么”

Q 是“我想找什么”；K 帮你挑资料；V 是真正读回来的内容。

假设你想知道“自行车链条掉了怎么办”。面前有几份资料，标题分别是《自行车维修》《做饭教程》《种花指南》。你会先看哪份跟问题更相关，再去读里面的具体方法。

Q：我要查什么？

“我要找修链条的方法。”

这是你这次找资料的需求。

K：这份资料讲什么？

“我这份讲自行车维修。”

像书名或目录，用来帮你判断它跟问题有没有关系。

V：里面具体说了什么？

“链条应该怎样装回去的具体步骤。”

这是你真正读到、带回来的内容。

你拿着自己的问题 Q，看各份资料的介绍 K，决定多参考哪份、少参考哪份。然后按这些份额，把它们的内容 V拿过来合并。

所以，Q 和 K 一起决定“参考谁、参考多少”；V 才是“参考到的具体内容”。几份资料可能都有用，因此可以同时参考多份，不一定只挑一份。

为什么 K 和 V 要分开？

因为《自行车维修》这个标题能帮你找到书，却不能直接教你修链条。你还得读正文。K 类似“用来挑选的介绍”，V 类似“挑好以后实际读取的内容”。

只改 Q：你换了要找的东西

原来想修自行车，后来想学做饭。资料还是那些资料，但这次你会更多参考另一份。

只改 V：资料正文换了

假设标题、目录都没变，只换正文。按原来的标题和目录，你仍分配同样的参考份额，但读回来的内容已经不同。

放到我们的五指相机里，怎么对应？

现在轮到处理拇指画面中的一小块。它看不全整个物体，可以参考食指、中指等画面里的信息：

拇指这一处的 Q

可以想成：“这次我该去找什么样的信息？”

各处提供的 K

可以想成：“我这里有什么线索，和你要找的有没有关系？”

各处提供的 V

确定参考份额后，实际送过来的那份图像信息。

如果这次算出来更应该参考食指，食指的 V 就占更大的份额。轮到处理食指画面的一小块时，再用食指这一处自己的 Q 去找信息。每一处都有自己的 Q、K、V，三个字母不是分别分给三台相机的。

网络实际不会说这些话。它把图像信息分别加工成三组数字，当作 Q、K、V；加工方法通过训练学会。上面的对话只是帮助理解这三组数字各自干什么。V 也不是“重要程度”，参考份额才是注意力权重。

记住这件事就够了：先用 Q 和 K 算“该参考多少”，再按这个比例，把 V 里的内容合起来。

先把实验中的 A 暂时当成《自行车维修》，C 暂时当成《做饭教程》。开始时，你想找的是修链条的方法。下面每个按钮都从这一起点开始，只换一个东西；点击第一列就能跳到对应实验。

换问题：只改 Q从“怎么修链条”换成“怎么做饭”。资料的介绍和正文都不动。参考份额换成 A 约 33%、C 约 67%，合并出来的内容也随之改变。

书名只是帮助对应按钮的故事，不是说 [1,0] 这些数字真的编码了“修链条”。百分比由教学数字算出，是合并内容的份额，不是资料正确率。只换介绍、不换正文是刻意隔离 K 的作用；实际网络改动输入时，往往会同时改变 Q、K、V。

理解这个分工后，再展开看数字、矩阵和“只改一项”的实验

1. 同一个 token，为什么能产生三个不同向量？

因为同一份输入分别乘了三套不同的权重矩阵。这里用一个只有两个数的 token 演示，暂省略 LayerNorm：

同一个输入 tokenx = [2, 1]分别经过三条线性映射 ↓

第一条分支：生成 Q

WQ = [1  0]
     [0  1]

Q = xWQ = [2, 1]

这一组权重保留原来的两个分量。

第二条分支：生成 K

WK = [0  1]
     [1  0]

K = xWK = [1, 2]

这一组权重交换两个分量的位置。

第三条分支：生成 V

WV = [1   1]
     [1  -1]

V = xWV = [3, 1]

第一个分量：2 + 1；第二个分量：2 − 1。

三个分支的输入相同，计算规则不同，输出就可以不同。上面的矩阵是人工选择的教学例子；真实 WQ、WK、WV 是训练学习的参数。

在 self-attention 中，每个 token 都生成自己的 Q、K、V。轮到 A 接收信息，就用 QA 与所有 K 比较，再汇总对应的 V；轮到 C 接收信息，就换用 QC。这些查询实际可并行计算，并不是“一台相机只负责 Q，另一台只负责 K”。

Q_A：当前检索条件

为什么只改一个 K，其他来源的比例也可能变？

所有来源共享 softmax 的分母。如果 C 的分数升高，它分到的比例通常变大，A 的比例相应变小，即使 A 的分数完全没变。改动一个 K 还可能影响其他查询对这个来源的分数；完整网络会为每个查询各算一行权重。

3. 为什么把 K 和 V 分开？

用于决定“读谁”的表示，不必和“读回什么”的内容表示相同。分开投影后，网络可以学习一套适合匹配的 K，再用另一套 V 表达要传递的信息。点击“换正文（只改 V_C）”：两个来源各自的读取比例保持不变，输出向量却发生变化，这正是两者分工的区别。

Q 与 K 也不要求完全相等。它们只需要能通过点积产生对当前任务有用的匹配分数；K 不是唯一编号，更不等于“某个物体面”的人工标签。

4. WQ、WK、WV 和 Q、K、V，哪些东西是学出来的？

名称它是什么什么时候变化
WQ、WK、WV模型的可学习参数训练时由损失反向传播更新；正常推理时保持固定。
Q、K、V由当前输入乘以上述权重算出的中间向量即使权重不变，输入改变也会使这些向量改变。
注意力权重 a根据当前 Q、K 算出的读取比例由当前匹配分数决定；不是保存好的固定“相机重要性”。

训练会根据最终任务的误差，调整这些投影矩阵。例如用预测的 top-view 与真实图像比较，误差通过后续网络反传，使匹配与传递的内容逐渐对预测更有帮助；无需手工规定哪个 Q 应当匹配哪个 K。

这里的类比和手工向量用于理解计算，不代表网络已经学会物体表面对应关系。高注意力不能保证两个 token 来自同一物理位置，也不能保证未观测面被准确恢复。

回到本页 SRT：经过 LayerNorm 的每个 token 有 768 维，每个头分别投影出 64 维 Q、K、V；12 个头有各自的投影。接下来可进入六个 token 的完整注意力实验。计算方式可核对 Attention 实现。

⑧ 多头、残差和 Transformer，是怎样搭起来的？

  
每条记录先参考其他位置的信息，再整理自己内部的信息。这两次加工都把结果加回原记录。把这些步骤装在一起，就是一个 Transformer block；再把多个 block 串起来，就构成这里的 Transformer 编码器主体。

1．多头：同一批资料，用多套规则分别参考

  
前面的一个头，会用 Q 表达“想查什么”，用 K 判断“该参考谁”，再按份额汇集 V 的内容。多头就是同时做多套这样的计算。各个头有自己学习到的 Q、K、V 投影权重，因此参考谁、取回什么，都可以不同。

  

    
  

  
“并排放”与“再混合”是两步：先把 12 份结果拼成一条长记录，再用学到的 WO 重新组合这些数。这里没有对 12 个头简单取平均。

  
每个头都能读取全部 245 条记录，并从完整的 768 维记录生成自己的 64 维 Q、K、V；哪些输入更有影响，由投影权重决定。这里不是把相机分给不同头，也不是把输入机械地切成 12 份。各头的关注方式由训练学习，没有指定的“颜色头”“形状头”。


  
2．残差：原记录留一份，再加上本次调整

  
可以想成改笔记：原来的笔记直接保留一条通路，加工网络负责算出本次的调整量。残差连接做的就是“原记录 + 调整量”，逐个位置相加。下面只用两个数演示；真正的每条记录有 768 个数。

  

    
原记录[2.0, 1.0]
＋
本次调整[0.5, −0.2]
＝
更新后的记录[2.5, 0.8]

  

  
调整量可以为正，也可以为负，所以某个数可以变大，也可以变小。这条直接通路让网络能在已有记录上逐步修改，也有助于训练时梯度的传播。

  
这里的“保留”指保留一条直接相加的通路，不是保证输出与输入相同。相加不会让 768 维变成 1536 维；这个实现也没有在相加后紧接一个 ReLU。

把一组记录写成矩阵 X；忽略批次维度，形状为 245 × 768。一个注意力头的计算是：

    
U = LayerNorm(X)                       → 245 × 768
Qₕ = U WQₕ，Kₕ = U WKₕ，Vₕ = U WVₕ     → 各为 245 × 64
Aₕ = softmax(Qₕ Kₕᵀ / √64)             → 245 × 245
Hₕ = Aₕ Vₕ                            → 245 × 64
MHA(U) = Concat(H₁, …, H₁₂) Wₒ         → 245 × 768

    
每个头有一张 245 × 245 的参考份额表 Aₕ；每行对应一条记录，行内份额相加为 1。拼接沿特征维进行，12 × 64 = 768；WO 是 768 → 768 的线性映射（式中省略实现里的偏置与 dropout）。

    
两次残差分别是：

    
Y  = X + MHA(LayerNorm(X))
X′ = Y + FFN(LayerNorm(Y))

    

      
LayerNorm：先整理数值尺度
以一条记录内部的 768 个数为一组，计算均值和方差后做标准化，再施加可学习的缩放和平移。不同记录不混在一起求均值。一个 block 内的两处 LayerNorm 也各有自己的参数。

      
FFN：把收到的信息再组合
768 个数 → Linear → 1536 个数
          → GELU → Linear → 768 个数
GELU 是非线性激活函数，作用与前面 ReLU 一样是提供非线性，但计算方式不同。同一个 block 中，各条记录使用相同的 FFN 权重，彼此独立计算。

    

    
这部分是结构讲解与教学示例，不是从已训练模型中读取的中间特征。12 头、每头 64 维、FFN 中间 1536 维和默认 10 个 block 对应 SRTEncoder 默认参数与 Attention / PreNorm / FeedForward / Transformer 实现，block 数可由配置覆盖。
